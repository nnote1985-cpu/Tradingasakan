## สิ่งที่วัด

คำถาม: ถ้าพอร์ตจำลองรัน N วัน ผลจะ "ผ่าน" เกณฑ์ของ Note บ่อยแค่ไหน และกฎที่ไม่มีฝีมือจะผ่านบ่อยแค่ไหน

| หัวข้อ | สมมติฐานที่ใช้ |
| --- | --- |
| ข้อมูลตั้งต้น | R5 บน development + validation 2022-04-12 → 2025-01-25 (1,019 วัน) ไม่ใช้ holdout |
| ขนาดผล (effect size) | ไม่ได้กำหนดเป้าล่วงหน้า ใช้พฤติกรรมในอดีตเป็น "ความจริง" ทั้งชุด ผลต่างรายวันเฉลี่ยเทียบ B&H = −0.012% (−4.5%/ปี) |
| ความแปรปรวน | ไม่ได้ใส่สมมติฐาน ใช้ค่าจริงจากการสุ่มซ้ำ (SD ของผลต่างรายวัน 1.97%) |
| ข้อมูลสัมพันธ์กัน | circular block bootstrap: การทดสอบตามเกณฑ์ใช้บล็อก 90 วัน สุ่มผลตอบแทน BTC และน้ำหนักที่ถือคู่กันทั้งบล็อกเพื่อคงลำดับและช่วงเทรนด์ ส่วนการทดสอบค่าเฉลี่ยผลต่างใช้บล็อก 30 วัน |
| กลุ่มควบคุม (no-skill) | สุ่มบล็อกน้ำหนักแยกจากบล็อกผลตอบแทน: exposure เท่าเดิมแต่จังหวะไม่เกี่ยวกับราคา |
| ต้นทุน | 0.10% + 2 bps ต่อส่วนที่เปลี่ยนน้ำหนัก |
| เกณฑ์ผ่าน | net > 0 และ (Sharpe > B&H หรือ max DD ≤ ครึ่งของ B&H) ในหน้าต่าง N วัน |
| จำนวนรอบ | 4,000 รอบต่อช่วงเวลา, seed 7 |

## ผล

| ช่วงเวลา | ผ่าน ถ้าพฤติกรรมอดีตซ้ำ | ผ่าน โดยกฎไม่มีฝีมือ |
| --- | --- | --- |
| 90 วัน | 14% | 32% |
| 1 ปี | 46% | 29% |
| 3 ปี | 68% | 24% |
| 10 ปี | 87% | 14% |

การทดสอบค่าเฉลี่ยผลต่าง (excess mean, one-sided 5%) ได้ power ต่ำกว่า 6% ทุกช่วง และสูตรวิเคราะห์หาจำนวนวันที่ power 80% ไม่ได้
เพราะผลต่างเฉลี่ยในอดีตติดลบ ส่วนที่ผ่านเกณฑ์ส่วนใหญ่มาจากเงื่อนไข drawdown ไม่ใช่ผลตอบแทนที่สูงกว่า

## วิธีอ่าน

- "ราว 10 ปี" เป็น **เวลาโดยประมาณภายใต้สมมติฐานข้างบน** (ใช้อดีตช่วงเดียวเป็นความจริง, บล็อก 90 วัน, เกณฑ์นี้)
  ไม่ใช่ข้อสรุปทั่วไป ถ้าเปลี่ยนเกณฑ์ ขนาดผลที่ต้องการตรวจ หรือขนาดบล็อก ตัวเลขจะเปลี่ยน
- ค่าเหล่านี้เป็น in-sample สำหรับกฎ R5 เพราะกฎถูกเลือกจากข้อมูลช่วงเดียวกัน จึงน่าจะมองโลกในแง่ดีเกินจริง
- การทดสอบ forward **ยืนยันความเหนือกว่าในเวลาอันสั้นไม่ได้** แต่ยังมีประโยชน์: ตรวจว่าระบบทำงานถูก วัดต้นทุนและเวลา fill จริง
  ดูพฤติกรรมและความเสี่ยงในสภาพตลาดใหม่ และใช้ปรับสมมติฐานสำหรับเวอร์ชันถัดไป
- เกณฑ์ ขนาดผลที่ต้องการตรวจ และวิธีจัดการ multiple comparisons สำหรับการทดลองยืนยันจริง ต้องล็อกก่อนเริ่ม (buildplan §24 Phase 6)
